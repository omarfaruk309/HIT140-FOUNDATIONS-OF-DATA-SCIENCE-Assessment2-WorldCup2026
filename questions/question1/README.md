# Question 1 — Goals

Open `question1.ipynb`, select the project `.venv` Python kernel, and run the cells from top to bottom.

Install dependencies if needed with `python -m pip install -r requirements.txt` using your selected environment.

The original input CSV is in `data/`. Running the notebook saves its outputs in `processed_data/`, `figures/`, `tables/`, and `results/` inside this folder.
